1. OVERVIEW OF CHANGES
--------------------------------------------------------------------------------
This update implements dynamic product pricing based on cup size (16oz Large vs.
22oz Grande) and replaces arbitrary manual finished-beverage stock tracking with
automatic, estimated raw inventory consumption. All consumption values, size
multipliers, and recipe definitions have been centralized into a single, easily
maintainable engine (`recipe_engine.php`) so staff can calibrate measurements
anytime without modifying frontend or database queries.

The optional "Track stock quantity" checkbox has been completely removed from
the UI and backend validation; all products now track stock consistently and
reliably through their underlying raw inventory supplies.

3. INVENTORY CONSUMPTION ENGINE (`recipe_engine.php`)
--------------------------------------------------------------------------------
- Centralized Architecture:
  * Located at: `c:\xampp\htdocs\cafeflow_v5-1\recipe_engine.php`
  * Single source of truth for all cup dimensions, scaling factors, and recipe
    ingredient assumptions.
- Standard Cup Sizes & Scaling Profiles:
  * 16oz (Large): Baseline multiplier 1.00; automatically maps to '16oz cup' & 'Flat lid'.
  * 22oz (Grande): Scaling multiplier 1.375 (~38% more volume); maps to '22oz cup' & 'Flat lid'.

  * Cleanly structured placeholder recipes per product/category:
    - Matcha: Matcha Powder (15g @ 16oz / 22g @ 22oz), Full Cream Milk (180ml / 250ml),

    - Americano: Espresso Beans (18g / 24g), Ice (140g / 180g), cup, lid, straw.

      Ice (120g / 150g), cup, lid, straw.
    - Coffee / Milk Tea / Fruit Tea category fallbacks.
  * Custom explicit ingredient links in `product_ingredients` take Priority 1,
    automatically scaled by the cup size volume factor and packaging requirements.
- How to Update Measurements Later:
  * To update any gram/ml/piece measurement, open `recipe_engine.php` and update
    the numbers in `ESTIMATED_CONSUMPTION_PROFILES` or edit custom product links
    in the Products tab. No other files need to be edited!

4. DEDUCTION TIMING & PROTECTION AGAINST INSUFFICIENT STOCK
--------------------------------------------------------------------------------
- Deduction Timing:
  * Orders placed via POS enter status 'Pending' on the Barista Queue.
  * PENDING, FAILED, or CANCELLED orders NEVER deduct raw inventory.
  * Deductions occur EXCLUSIVELY and ATOMICALLY when the barista marks an order
    'Completed' in `complete_order.php`.
  * Status is checked with `FOR UPDATE` row locking to prevent duplicate deductions.
- Pre-order & Pre-completion Availability Checks:
  * `checkout.php` verifies that the cafe has sufficient raw materials before
    accepting an order into the queue.
  * `complete_order.php` locks inventory rows and validates that all required
    supplies exist before deducting.
  * If raw supplies are insufficient:
    - Order is rejected with a clear, specific message:
      "Cannot complete order: Insufficient stock for '[Item]'. Order requires X, but only Y available (short by Z)."
    - Prevents negative inventory balances.
  * Real-time stock status badges ('In Stock', 'Low Stock', 'Out of Stock') in POS
    are evaluated directly from live raw inventory supplies.

7. OUT-OF-STOCK CLICK GUARD & CARD LAYOUT FIX
--------------------------------------------------------------------------------
- Disabled Out-of-Stock Card Clicks:
  * When a product's raw stock is 0 or depleted (`stock_state === 'out'`), the card
    is now tagged with class `.is-out-of-stock` and `aria-disabled="true"`.

  * In `checkout.php`, the backend enforces that no out-of-stock product can be
    submitted in an order.
- Clean Price Range Display:
  * Changed the card pricing display from long text (`16oz ₱130.00 · 22oz ₱150.00`)
    to clean, concise range formatting (`₱130.00 – ₱150.00`).
  * Updated `.item-foot` with flexible spacing so prices and stock tags never collide
    or wrap awkwardly.

8. CUP SIZE LOGIC ENHANCEMENT & "TALL" (16oz) LABEL UPDATE
--------------------------------------------------------------------------------
- Changed 16oz Size Label from "Large" to "Tall":
  * 16oz is now officially "Tall" and 22oz is "Grande".
  * Updated across database schema (`db.php`), default inserts, existing records in
    `product_size_prices` and `transaction_items`, size popover dialog (`index.php`),
    product management forms, and JavaScript validation.
- Per-Cup-Size Real-Time Stock Availability (`recipe_engine.php` & `fetch_menu.php`):
  * Previously, checking 16oz stock caused the whole product to be marked "Out of stock"
    even when 22oz cups (500 pcs) were available in inventory.
  * Implemented `evaluate_single_size_stock()`: Evaluates inventory sufficiency for each
    size individually (16oz vs 22oz).
  * Products are only marked completely "Out of stock" if ALL sizes are depleted (or if
    a core ingredient like coffee beans/matcha powder is 0).
  * If 16oz cup is 0 pcs but 22oz cup has stock, product state is `partial`:
    - Menu card remains clickable, does NOT show "Out of stock", and displays a
      helpful badge: "Grande only".
    - Clicking the card opens the size popover:
      * Tall (16oz) button is disabled with an "Out of stock" indicator.
      * Grande (22oz) button is enabled (₱150.00) and can be added to the order.
    - If 22oz cup is 0 and 16oz is in stock, card displays "Tall only" and Tall is orderable.
    - Backend `checkout.php` validates inventory sufficiency for the exact cup size ordered.
