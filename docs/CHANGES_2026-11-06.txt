Release Date: November 06, 2026 | Environment: PHP 8.2 / MariaDB / Apache (XAMPP) | Status: Complete & Verified

================================================================================
1. EXECUTIVE SUMMARY OF IMPLEMENTED CHANGES
================================================================================
This release delivers critical stability fixes, complete transition to a zero-VAT (non-VAT) operational model, expanded user interface layouts, enhanced transaction history filtering with sticky headers, and enterprise Excel reporting:

• Critical JavaScript Syntax & Runtime Freeze Resolution:
  - Eliminated two blocking parse-time syntax errors in assets/js/script.js: a rogue closing brace ('}') at line 1484 that closed the script IIFE prematurely, and an orphan VAT calculation remnant at line 6238 in the receipt builder.
  - Fully restored client-side execution across all roles: #menuGrid instantly renders all 42 product cards, price tags, and size chips; the queue background poller connects immediately, transitioning the top bar indicator from 'CONNECTING...' to '● LIVE' with real-time active order counts.

• Complete 12% Value-Added Tax (VAT) Removal & Discount Model Overhaul:
  - Successfully transitioned the system from a 12% VAT regime to a non-VAT operational model across all application layers (POS checkout UI, cart state calculations, backend checkout API, database records, e-receipt dialogs, and Excel export summaries).
  - Senior Citizen & PWD discounts now calculate as a clean 20% deduction directly on the gross subtotal (e.g. ₱100.00 subtotal yields ₱20.00 discount, ₱0.00 tax, and ₱80.00 payable total).
  - Maintained strict OSCA / PWD ID or Booklet number verification (minimum 3 characters required) to prevent fraudulent claims.
  - Preserved custom promotional discounts (custom % from 1% to 50% and fixed voucher deductions) operating under the zero-VAT model.
  - Completely removed the '12% VAT (Included)' line item from the POS order summary, receipt modal dialog, and Excel summaries.

• Account Management UI Expansion (Zero Horizontal Scroll):
  - Redesigned the #accountsModal container in assets/css/auth.css with an executive wide-canvas layout (max-width: min(96vw, 1480px)).
  - Completely eliminated horizontal scrollbars across all desktop, laptop, and tablet viewport resolutions (1920x1080, 1600x900, 1366x768, 1280x800).
  - All 8 table columns (Full Name, Username, Email, Role, Status, Created, Last Login, Actions) render with ample breathing room, eliminating cramped or clipped action buttons ('Edit', 'Reset', 'Deactivate').

• Transaction History Scroll & Live Instant Search:
  - Implemented a dedicated vertical scrollable table viewport (.tx-table-container, max-height: 440px with sticky column headers) on both Barista and Manager sales report interfaces.
  - Added an instant live search toolbar allowing immediate filtering across receipt #, item names, payment methods, order status, GCash reference codes, timestamps, and order totals.
  - Upgraded api/transactions_api.php with backend ?search= filtering alongside multi-day range (?start=&end=) and month (?month=) query support.

• Complete CSV Export Retirement & Enterprise Excel (.xlsx) Standardization:
  - Permanently retired and removed api/export_csv.php and related CSV triggers in index.php and api/report.php.
  - Standardized all reporting on the multi-worksheet executive Excel generator (core/excel_generator.py with pure-PHP OpenXML fallback in api/export_excel.php), featuring:
    * Sheet 1: 'Executive Dashboard' (6 KPI summary cards, Category Sales Mix, Payment Breakdown, Non-VAT Sales Summary).
    * Sheet 2: 'Itemized Sales Ledger' (21 columns, frozen header row, auto-filter, zebra row styling, dynamic =SUBTOTAL() formulas).
    * Sheet 3: 'Product Performance' (menu item revenue ranking, unit counts, and % sales contribution).

• Repository Cleanliness & Scratch File Removal:
  - Deleted all temporary diagnostic and test scripts (scratch_*.py) from the repository root, ensuring zero untracked test bloat in version control.
