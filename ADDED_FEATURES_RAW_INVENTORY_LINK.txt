2. SELECTABLE MULTI-ITEM RAW INVENTORY SUPPLY LIST
--------------------------------------------------------------------------------
- Replaced the legacy single-item <select> dropdown with a clean, structured,
  vertical list of raw supplies retrieved live from inventory_api.php.
- Each inventory item features its own dedicated checkbox allowing simultaneous
  multi-selection. Selecting one item never deselects other selected items.
- Displays comprehensive, concise details for each raw inventory item:
  * Item Name (bold, stylized in espresso theme)
  * Current Available Stock with Unit of Measurement (e.g., "2,000.00 g", "48.00 pcs")
  * Real-time Stock Status Badge (OK "In Stock", Low "Low Stock", Out "Out of Stock")
- Each selected item displays an inline deduction amount input:
  * Example: [ 18 ] g / order, [ 200 ] ml / order
  * Cashiers/managers can customize the exact quantity consumed per sold order.
  * Inputs isolate click events so entering deduction numbers never toggles checkboxes.

--------------------------------------------------------------------------------
3. FULL DATABASE & ORDER PROCESS INTEGRATION (MULTI-INGREDIENT RECIPES)
--------------------------------------------------------------------------------
- Database Schema Expansion:
  * Created the `product_ingredients` table in schema.sql, db.php (ensure_schema),
    and migrate.php:
      - id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY
      - product_id INT UNSIGNED NOT NULL (FK -> menu_products.product_id ON DELETE CASCADE)
      - item_id INT UNSIGNED NOT NULL (FK -> inventory.item_id ON DELETE CASCADE)
      - deduction_amount DECIMAL(10,2) NOT NULL DEFAULT 1.00
      - UNIQUE KEY (product_id, item_id)
  * Maintains backward compatibility by syncing the primary linked item into
    `menu_products.linked_inventory_id` and `deduction_amount`.
- Non-Destructive Selection:
  * Toggling checkboxes and saving products strictly registers recipes. It NEVER
    causes premature or unintended inventory deductions.
- Authentic Barista Order Deduction:
  * In complete_order.php, when the barista marks an order "Completed":
    - Automatically calculates quantity sold x deduction amount for ALL linked
      ingredients in `product_ingredients` across the whole order.
    - Atomically deducts each ingredient from `inventory.current_stock` using
      database transaction locking and GREATEST(..., 0) safety bounds.
    - Continues to safely deduct direct `stock_quantity` for tracked items that
      do not link to raw inventory supplies.
    - Checks all touched recipe ingredients and flags low-stock alerts.
- Menu Grid Stock Status Integration:
  * In fetch_menu.php and products_api.php, a product's real-time stock status
    (ok, low, out) is dynamically evaluated across ALL linked ingredients.
    If any single required ingredient is depleted, the product shows "Out of stock";
    if any is at or below its restock threshold, it shows "Low stock".

4. DEDICATED VERTICAL SCROLLABLE LIST WITH SCROLL-CHAINING PREVENTION
--------------------------------------------------------------------------------
- Implemented a dedicated scrollable area (.supply-list-container) with a 250px
  max-height and custom-styled minimalist scrollbar.
- Employs `overscroll-behavior: contain` to prevent scroll chaining so mouse wheel
  or trackpad scrolling inside the list never scrolls the modal or page behind it.
- Keeps the modal header, search input, and action buttons fixed and visible
  while the inventory items scroll.
- Checkbox selections and entered deduction amounts are stored in application
  state (selectedSupplies Map) and are 100% preserved during scrolling.

--------------------------------------------------------------------------------
5. REAL-TIME SEARCH & FILTERING BAR
--------------------------------------------------------------------------------
- Integrated a search bar directly above the supply list with a clear 🔍 icon
  and an instant ✕ clear button.
- Live case-insensitive filtering as the cashier/manager types:
  * Matches raw supply names (e.g. searching "bean" matches "Espresso Beans").
  * Matches unit of measurement (e.g. searching "ml" or "g").
  * Matches numeric item IDs.
- Non-destructive filtering:
  * Hiding an item through a search filter does NOT deselect it or erase its
    custom deduction amount.
  * Clearing search immediately restores the entire list with selections intact.
